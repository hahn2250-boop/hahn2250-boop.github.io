Packstart Poster

A small personal desktop tool for Windows.

Packstart Poster uploads short videos that I created myself to my own TikTok account at times I planned in advance. It reads my local posting plan, takes the planned video and caption, and publishes it with the official TikTok Content Posting API.

The tool runs only on my own computer. There is no server, no website login and no other users' data.

How it works

  1. I sign in once with TikTok (Login Kit) and authorize the scopes user.info.basic and video.publish.
  2. When a planned time is reached, the tool uploads the video file from my computer to TikTok (Direct Post).
  3. The caption and hashtags come from my own posting plan.
